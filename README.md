# jeremyM

An educational React site about how computed tomography (CT) helps clinicians
answer medical questions.

[Open the site preview](https://urban-space-parakeet-xrvwrwwwvpr5399pq-5173.app.github.dev/)

## Run locally

```sh
npm install
npm run dev
```

The production build is generated in `dist/` with `npm run build`.
